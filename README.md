# Kumori tools

Small, standalone tools from [Kumori](https://kumori.ai), shared as they prove themselves.
Each one runs on its own: no Kumori account, no Kumori infrastructure.

| tool | what it does |
|:--|:--|
| [canary](canary/) | Proves a test can fail. A test that passes on your change *and* on the code before it doesn't prove your change. |

Each tool has its own README and tests. More arrive one at a time, once they've shown they help.

Also open from Kumori: [sparebrAIns](https://github.com/kumori-ai/sparebrains), where free models prove math in Lean 4 and the kernel is the only judge.
